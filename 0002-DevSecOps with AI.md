# COURSE LEARNING OUTCOMES

By completing this course, learners will be able to:

1. Understand DevOps, DevSecOps and Secure SDLC principles.
2. Work with Linux, networking, Git, GitHub and Python.
3. Provision and secure AWS infrastructure using Terraform.
4. Build, optimize and secure Docker container images.
5. Deploy and secure applications on Kubernetes.
6. Implement automated CI/CD pipelines using Jenkins.
7. Integrate SAST, SCA, DAST, container and IaC security scanning.
8. Implement automated security gates in CI/CD pipelines.
9. Manage application and pipeline secrets using AWS Secrets Manager.
10. Generate SBOMs and implement container image signing.
11. Monitor applications and AWS infrastructure.
12. Perform basic security incident investigation.
13. Use AI for vulnerability analysis and security report generation.
14. Build a Python-based AI security assistant.
15. Implement and demonstrate an end-to-end DevSecOps platform.
